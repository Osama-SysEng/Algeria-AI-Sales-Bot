# Algeria AI Sales Bot — نظام مبيعات ذكي للسوق الجزائري

**روبوت مبيعات ذكي متكامل يدعم العربية والفرنسية والدارجة الجزائرية — مصمم لشركات MLM والشركات الناشئة.**

---

## ما هو Algeria AI Sales Bot؟

روبوت مبيعات ذكي متكامل يدعم اللغتين العربية والفرنسية والدارجة الجزائرية, مصمم لتشغيل عمليات المبيعات وتحسين مهارات المبيعات لفريق العمل. يجمع بين الذكاء الاصطناعي وتقنيات التسويق الحديث لتقديم حلول ذكية لتشغيل عمليات المبيعات.

## التقنية
- FastAPI فقط (لا Node.js ولا PostgreSQL ولا Redis في هذه النسخة — مخازن في الذاكرة لغرض النموذج والاختبارات)
- LLM خادمي فقط مع fallback يدوي، واعتماد بشري قبل أي إجراء

## البدء السريع
```bash
cd Algeria-AI-Sales-Bot/app/algeria-ai-sales-bot
cp .env.example .env
pip install -r requirements.txt
uvicorn backend.app.main:app --reload
# لوحة العمل: http://localhost:8000/dashboard
```

> ملاحظة: المسار الحقيقي للكود هو `Algeria-AI-Sales-Bot/app/algeria-ai-sales-bot/` (تعشيش ثلاثي)،
> ووحدة الدخول هي `backend.app.main:app` وليست `backend.main:app`.
> ملف التشغيل بالحاويات: `Algeria-AI-Sales-Bot/app/algeria-ai-sales-bot/Dockerfile`.
