# Algeria AI Sales Bot — الإصدار التشغيلي الآمن

هذه الحزمة هي مساحة عمل مبيعات داخلية باللغة العربية/الدارجة الجزائرية. تتيح إنشاء العملاء المحتملين، وإنتاج **مسودات** مدعومة بالـLLM، وتسجيل اعتماد بشري، وعرض مؤشرات تشغيلية. لا تتصل النسخة الحالية بـTelegram أو CRM ولا ترسل أي رسالة خارجية؛ إذ تعيد واجهة الاعتماد `delivery_performed=false` صراحةً.

## التشغيل المحلي

انسخ `.env.example` إلى `.env` وضع أسرار بيئة محلية فقط. ثبّت التبعيات ثم شغّل:

```bash
pip install -r requirements.txt
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

تظهر لوحة العمل في `http://localhost:8000/dashboard`، وتوجد وثائق التفصيل في `docs/` داخل هذا المجلد وفي مجلد `docs/` المرافق للإصدار.

| العنصر | الوضع في هذه النسخة |
|---|---|
| الوصول التشغيلي | `X-Operator-Token`، مع فشل مغلق عند الإنتاج إذا غاب إعداد المشغل. |
| LLM | خادمي فقط، ومخرجات JSON منظمة، وfallback يدوي عند غياب الإعداد. |
| الموافقة | تسجل الإجراء والتدقيق ولا تنفذ التسليم. |
| Telegram وCRM | متغيرات وتجهيزات staging فقط؛ تحتاج موصلًا رسميًا منفصلًا واختبارات توقيع/opt-out قبل أي تفعيل. |
| التخزين | المخازن في الذاكرة لغرض النموذج والاختبارات؛ ليست قاعدة بيانات إنتاجية. |

> لا تغيّر `ENABLE_EXTERNAL_DELIVERY` إلى `true` لمجرد إكمال الإعداد. يلزم أولًا موصل موقع، outbox idempotent، RBAC، قاعدة بيانات مدارة، اختبار replay وopt-out، وموافقة تشغيلية مستقلة.
