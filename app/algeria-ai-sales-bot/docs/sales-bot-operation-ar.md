# تشغيل Algeria AI Sales Bot بأمان

المسار التشغيلي يفصل بين **مسودة رد يكتبها الذكاء الاصطناعي** و**إرسال فعلي يوافق عليه مسؤول مبيعات**. واجهة API تسجل الإذن فقط ولا تستدعي Telegram أو WhatsApp أو Google Sheets أو أي قناة خارجية بنفسها.

| عنصر | الحالة في الحزمة | شرط التفعيل الفعلي |
|---|---|---|
| مسودة دارجة | خدمة خادمية منظمة بمخرجات JSON. | مفتاح نموذج خادمي ومراجعة جودة اللهجة والمنتج. |
| رسالة خارجية | متوقفة عمدًا. | موصل رسمي، webhook موقّع، موافقة ثانية وسجل تسليم. |
| العروض والأسعار | لا يخترع النموذج سعرًا أو خصمًا أو موعدًا. | كتالوج موثق ومحرك تسعير موثوق. |
| التحليلات | تعتمد counts وحالات وaudits فقط. | تخزين مدارة، RBAC، وسياسة احتفاظ. |

> لا ترسل بيانات العملاء أو المحادثات لنموذج خارجي قبل اعتماد الشركة للمعالجة ومدة الاحتفاظ وإخفاء البيانات غير اللازمة.
