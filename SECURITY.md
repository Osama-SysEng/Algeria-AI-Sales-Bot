# Security Policy

## Reporting a vulnerability

- Do not open a public issue for security vulnerabilities.
- Report privately through a GitHub private security advisory or by
  contacting the repository maintainers directly.
- Include: affected version/commit, steps to reproduce, and impact.

## Basics

- Never commit secrets (API keys, passwords, tokens) to the repository.
- Rotate credentials and keys regularly and immediately after any
  suspected exposure.
- Keep dependencies up to date and review security advisories.
